---
description: Mulai satu tahap pengembangan dari folder prompts/ (contoh /tahap 04)
argument-hint: <nomor tahap, contoh 04>
---

Kita akan mengerjakan tahap **$ARGUMENTS**.

1. Cari file `prompts/$ARGUMENTS-*.md` lalu baca seluruh isinya.
2. Baca `PROGRESS.md`. Jika ada tahap sebelumnya yang belum ✅, beri tahu saya
   dan tanyakan apakah tetap lanjut.
3. Baca semua dokumen di `docs/` yang disebut di prompt tahap tersebut.
4. Jalankan instruksi di bagian **Prompt** pada file tahap itu.
5. **Jangan mengubah file apa pun dulu.** Susun rencana berisi:
   - daftar file yang akan dibuat / diubah
   - keputusan desain penting dan alasannya
   - pertanyaan untuk hal yang ambigu di dokumen
   - daftar test yang akan ditulis
6. Tunggu persetujuan saya sebelum mulai menulis kode.
7. Setelah disetujui, ubah status tahap di `PROGRESS.md` menjadi 🟨.
